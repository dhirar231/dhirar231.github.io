Configuration du Réseau

Plan d'Adressage IP

Le plan d'adressage utilise la technique VLSM (Variable Length Subnet Mask) pour une allocation efficace des adresses IP selon les besoins de chaque département.

Configuration des Routeurs
Routeur Interface Adresse IP Masque Réseau Area OSPF
RZ1 (Web) FastEthernet0/0 172.24.0.1 /18 (255.255.192.0) 172.24.0.0/18 Area 0
RZ2 (IT) FastEthernet0/0 172.24.64.1 /21 (255.255.248.0) 172.24.64.0/21 Area 0
RZ3 (DB) FastEthernet0/0 172.24.72.1 /23 (255.255.254.0) 172.24.72.0/23 Area 0
RZ4 (NFS) FastEthernet0/0 172.24.74.1 /24 (255.255.255.0) 172.24.74.0/24 Area 0
Note : Tous les routeurs participent à l'area 0 OSPF pour assurer une convergence rapide du routage.

Configurations IPSec pour tous les départements avec le routeur backbone principal
RZ1
Routeur Web/Marketing - VLAN 10 (172.24.0.0/18) 
! Phase 1 — ISAKMP (Chiffrement Web/Marketing)
crypto isakmp policy 20
 encr aes 256
 hash sha256
 authentication pre-share
 group 14
 lifetime 28800

crypto isakmp key WEBVPN address 203.0.113.53

! Phase 2 — IPsec Transform Set
crypto ipsec transform-set TS_WEB esp-aes 256 esp-sha256-hmac
 mode tunnel

! ACL VPN (Trafic vers/depuis Backbone)
ip access-list extended VPN_WEB
 permit ip 172.24.0.0 0.0.63.255 172.24.64.0 0.0.31.255

! Crypto Map
crypto map CMAP_WEB 10 ipsec-isakmp
 set peer 203.0.113.53
 set transform-set TS_WEB
 match address VPN_WEB

! Interface WAN
interface GigabitEthernet0/0
 ip address 203.0.113.10 255.255.255.252
 crypto map CMAP_WEB
 ip nat outside

! NAT Exemption pour VPN
ip access-list extended NAT_WEB
 deny ip 172.24.0.0 0.0.63.255 172.24.64.0 0.0.31.255
 permit ip 172.24.0.0 0.0.63.255 any

ip nat inside source list NAT_WEB interface GigabitEthernet0/0 overload

Résumé des configurations par département :
  • RZ1 - Web/Marketing : AES-256/SHA256, Group 14, accès modéré
  • RZ2 - IT : AES-256/SHA512, Group 16, sécurité maximale
  • RZ3 - Base de Données : AES/SHA, Group 2, accès restreint
  • RZ4 - NFS : AES-128/SHA, Group 5, optimisé performance
Les ACLs VPN doivent être symétriques entre les routeurs départementaux et le backbone. Les clés pré-partagées doivent être identiques de chaque côté.
