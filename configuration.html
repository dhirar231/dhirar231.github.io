Configuration du Réseau

Plan d'Adressage IP

Le plan d'adressage utilise la technique VLSM (Variable Length Subnet Mask) pour une allocation efficace des adresses IP selon les besoins de chaque département.

Sécurité et NAT

Configuration NAT Avancée sur RZ1

Le routeur RZ1 implémente une architecture NAT (Network Address Translation) sophistiquée pour sécuriser et optimiser l'accès Internet de l'ensemble du réseau d'entreprise.

Interface externe: GigabitEthernet0/0 | Pool NAT: 203.0.113.0/28
Mécanismes NAT Déployés
  • PAT (NAT Overload)
    Multiplexage des sessions sur adresses IP publiques
  • NAT Statique pour Serveurs
    Serveurs Web/Marketing et Base de Données
  • NAT Dynamique par Département
    Pools dédiés pour chaque département
Architecture VPN Backbone-Départements
Tunnels IPSec Site-à-Site 4 Tunnels Actifs
  • Chiffrement AES-256-GCM pour tous les tunnels
  • Authentification pré-partagée unique par département
  • DH Group 14 pour échange de clés
  • MTU ajusté à 1400 pour performance optimale

Isolation des Départements Sensibles

Routage Inter-Département
